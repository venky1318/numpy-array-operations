# NumPy Array Operations

## Overview

This project demonstrates element-wise addition, subtraction, multiplication, and division using two NumPy arrays.

## Objectives

- Create two NumPy arrays.
- Perform mathematical operations.
- Inspect array shapes and data types.
- Understand NumPy vectorization.

## Technologies Used

- Python 3
- NumPy
- Visual Studio Code

## Installation

Install Python 3 and run:

```bash
python -m pip install -r requirements.txt
```

## How to Run

```bash
python array_operations.py
```

## Sample Data

Array A: `[10, 20, 30, 40, 50]`

Array B: `[2, 4, 5, 8, 10]`

## Results

| Operation | Result |
|---|---|
| Addition | `[12, 24, 35, 48, 60]` |
| Subtraction | `[8, 16, 25, 32, 40]` |
| Multiplication | `[20, 80, 150, 320, 500]` |
| Division | `[5, 5, 6, 5, 5]` |

## Project Files

This project shows how NumPy performs element-wise mathematical calculations and supports efficient numerical processing through vectorization.
